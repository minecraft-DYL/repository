# BBS Voice · 人声轨道

给 **BBS mod**（Minecraft 1.20.4 / Fabric）加一种新的轨道：**人声轨道**。
输入一句台词，mod 会在本地**离线**把它合成为语音，像剪辑软件的 AI 配音一样贴在时间轴上，并且：

* **配音人物**可切换（低沉男声 / 标准男声 / 温柔女声 / 童声 / 老人 / 机器人 / 耳语…）
* **音量**可调，并且支持**关键帧曲线**
* **语速**可调，并且支持**关键帧曲线**
* 支持**自动适配轨道长度**：台词比轨道长时整条加速，避免被截断
* 支持**自己录音配音**：录一段自己的声音，直接当这条轨道的配音
* 另外还有音调、起始偏移、声调开关，以及一组音色细节参数（基频 / 音色 / 气声 / 颤音 / 抖动 / 明亮度 / 声源）

全部合成在本地完成：**不联网、不调用任何 TTS 服务、不需要 API key、不需要 Python**。

## 1. 环境要求

| 组件 | 版本 |
| --- | --- |
| Minecraft | 1.20.4 |
| Fabric Loader | ≥ 0.15.0 |
| Fabric API | 任意 1.20.4 版本 |
| BBS mod | **2.2（1.20.4）** |
| Java | ≥ 17 |

> ✅ 本 mod 针对 **BBS 2.2（1.20.4）** 编译，`fabric.mod.json` 里声明依赖 `bbs >= 2.2`。
> 走的是 BBS 官方 addon API（`bbs-addon` 入口 + 事件总线注册剪辑/设置），**没有任何 mixin**。

## 2. 安装

1. 把 Fabric Loader + Fabric API + BBS mod 装好。
2. 把 `bbsvoice-1.0.0-1.20.4.jar` 放进 `mods/`。
3. 启动游戏。

## 3. 使用

安装后会多出**两种**人声轨道，分别对应两种使用场景：

### 3.1 影片级人声轨道（整部片子的旁白 / 配音）

在**摄影机时间轴**上右键 → `添加剪辑（Add clip）` → **人声配音**。

它和 `bbs:audio`、`bbs:subtitle` 是同一层级，适合旁白、独白、整片统一配音。

### 3.2 演员级人声轨道（每个角色自己的台词）

在**角色编辑器（Replay）的动作轨**里右键 → 添加动作 → **人声配音**。

每个角色一条，默认带 3D 空间音效（按角色位置播放，距离越远越轻），适合多角色对话。

### 3.3 面板说明

打开人声剪辑后，面板里有：

| 分组 | 参数 | 说明 |
| --- | --- | --- |
| 配音文本 | 输入框 / **编辑文本** | 这条轨道要说的话。支持多行，标点（，。！？）会自动变成停顿 |
| 配音人物 | **选择…** | 打开人物列表，选一个就会把该人物的全部音色参数写进这条轨道 |
| | **声调** | 打开时按普通话四声朗读，关闭时用平调 |
| 混音 | 音调 | 整体音高倍数（0.25–4.0） |
| | 音量 | 整体音量（0–4） |
| | 语速 | 整体语速（0.25–4） |
| | 偏移 | 从合成音频的第几秒开始播（正值跳过开头），单位：秒 |
| 音色细节 | 基频 / 音色 / 气声 / 颤音 / 抖动 / 明亮度 / 声源 | 人物预设只是起点，这里可以逐条微调；**每条轨道保存自己的值，互不影响** |
| 音量曲线 / 语速曲线 | 开关 | 打开后这条轨道会创建真正的关键帧曲线（音量 = 音量 × 曲线值，语速同理） |
| 合成状态 | 状态 / 打开缓存文件夹 / **重新合成** | 见第 4 节 |

**曲线**是真正的 BBS「可动画数值」，打开开关后曲线轨道就被创建，在 **BBS 的关键帧时间轴**上编辑即可
（横轴单位是**影片帧**，相对剪辑起点；纵轴 1.0 表示原值）。
例如想让一句话从很轻渐强到很响：在音量曲线 0 帧放 `0.2`，40 帧放 `1.5` 即可。

### 3.4 用你自己的录音当配音

1. 面板 → **配音来源** → 切到 **我的录音**。
2. 点**麦克风**图标 → 打开 BBS 自带的录音界面（设备选择 / 电平条 / 计时）→ 录完确认。
3. 录音存到 `config/bbs/assets/audio/`，并自动成为这条轨道的配音。也可以点**喇叭**图标直接挑一个已经在音频文件夹里的文件。
4. 录音和离线合成享受同样的**音量曲线 / 语速曲线 / 自动适配 / 3D 播放**。

### 3.5 自动适配轨道长度

面板 → **混音** → **自动适配轨道长度**：开启后，如果配音比轨道长，会整条加速到刚好在轨道内放完
（最长 4 倍速），而不是被硬生生截断。加速靠播放速率实现，所以**音调会一起变高**——
这跟剪辑软件里"变速不变调"不同，是本 v1 的取舍。

> **剪辑长度要够长**：合成出来的语音长度由文本决定，剪辑本身不会自动变长。
> 如果台词被截断，把剪辑右边缘往右拖到足够长即可（状态栏显示「已就绪」时就已经合成好了，可以先播一遍听长度）。

## 4. 合成与缓存

* 第一次播放（或在面板里看到状态变成「已就绪」）时，mod 会在**后台线程**合成这句话。
* 结果写到 `config/bbs/assets/audio/bbsvoice/<签名>.wav`，之后直接读缓存。
* 「签名」由**会改变音频本身的东西**决定：文本 + 全部音色参数 + 采样率。
  改文本 / 换人物 / 调基频 → 会重新合成；**调音量、语速、音调、曲线 → 不会重新合成**，
  因为这些是播放时实时施加的（所以可以随便打关键帧，不会触发反复合成）。
* 「重新合成」按钮会删掉当前签名对应的缓存并重新排队。
* 缓存文件数量上限由设置里的 `缓存数量` 控制，超出会按时间删除最旧的。
* 任务量积累时合成会排队（单线程后台队列），不会卡游戏。

## 5. 设置

`BBS mod 设置` → **BBS 配音**：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 默认配音人物 | 男声 · 标准 | 新建轨道时使用的人物 |
| 默认音量 / 默认语速 | 1.0 | 新建轨道时的初值 |
| 采样率 | 22050 | 越高越清晰，合成越慢、文件越大 |
| 自动合成 | 开 | 关掉后只有点「重新合成」才会合成 |
| 演员 3D 人声 | 开 | 角色轨道按角色位置播放 |
| 缓存数量 | 256 | 缓存 wav 上限 |

## 6. 百分比确认过的已知限制（请先读这一段）

1. **音质**：这是**纯离线共振峰（source-filter）合成**，不是神经网络 TTS。
   男声/女声/童声/机器人这些音色能听出区别，普通话四声也有音高曲线，
   但**机械感明显、不自然**——它顶的是「不需要联网、不需要素材、随时能用」，
   而不是「和真人一样」。想要真人级效果请另配真实录音。
   注意：早期版本（缓存签名 v1）因为声源在高频掉得太快，`i/e/ü` 这类高共振峰元音
   会被饿成低频轰鸣、整句听起来像"怪物"。v2 已按唇辐射加预加重修正（见第 7 节），
   旧缓存不会自动失效的部分见第 12 条。
2. **语速 = 变速变调**：语速是通过播放速率实现的（磁带原理），
   所以语速 1.5 倍时音高也会升 1.5 倍。这是 v1 的取舍，已在曲线里做了补偿提示。
3. **相同内容的两次播放会共用同一个音源**：BBS 的 `playUnique` 按资源去重，
   所以「文本+音色完全相同」的两条轨道同时播放时，实际上只有一个在响（后一条会追赶前一条的位置）。
4. **多音字**：每个汉字只取常用读音（如「的」读 de、不区分 dí/dì），没有上下文消歧。
5. **英文**：规则式拼读（letter-to-sound），可懂但不地道。
6. **演员轨道的暂停判定**：影片帧超过 250ms 没有推进就认为暂停并暂停音频；
   极端卡顿（20fps 以下）时可能出现短暂停顿。
7. **未做联机同步**：人声只在客户端本地合成与播放（和 BBS 自身的音频剪辑行为一致），
   服务器上的其他玩家看不到/听不到。
8. **录音用的是 BBS 自带的录音界面**：采集走 BBS 的 OpenAL 录音，能不能录取决于系统里有没有可用录音设备。
   本 mod 只负责把录下来的文件挂到这条轨道上，不做自己的采集实现，也不做"没麦克风"的兜底提示；
   真录不了时可以先在别处录好，再用**喇叭**按钮从音频文件夹里挑文件。
9. **自动适配上限 4 倍速**：再长也不继续加速了（宁可截断，也不让声音变成鸭子叫）。
10. **曲线在 BBS 的关键帧时间轴上编辑**：打开开关只是创建曲线轨道，关键帧本身用 BBS 自己的编辑器打。
11. **要等游戏的音频引擎就绪才会出声**：OpenAL 是 Minecraft 自己初始化的。在它就绪之前直接碰 OpenAL
    不只是失败一次——LWJGL 的能力类会初始化失败并**永久坏掉**，连游戏自带的音效一起完蛋。
    所以本 mod 会先安全地探测 AL 能力是否就位（不触发那个坏掉的初始化），没就位就安静等待、
    不播也不崩。副作用：刚进标题界面那几秒（音频引擎常常还在启动）可能还没声音，之后就正常。
12. **BBS 读 wav 时会往日志里打一条 `java.io.EOFException` 堆栈**：那是 BBS 自己的 wav 读取器
    把"chunk 读完"当成 EOF 并顺手 `printStackTrace()`，音频本身加载成功（时长、播放都正常），
    属于 BBS 侧的日志噪音。

## 7. 工作原理

```
文本 ──▶ Phonemizer ──▶ Phone 序列 ──▶ SpeechSynthesizer ──▶ PCM ──▶ WavFile
         │                │                │
         │                │                └─ 声门脉冲/方波/噪声源
         │                │                   → 唇辐射预加重（+6dB/oct，见下）
         │                │                   → 4 个时变共振峰谐振器
         │                │                   → 明亮度低通 → DC 阻断 → 归一化
         │                └─ 声调轮廓（阴平55 / 阳平35 / 上声214 / 去声51）+ 句尾降调 + 停顿
         └─ 汉字 → 拼音（内置 26781 字表）→ 声母+韵母 → 音素
            英文 → 规则拼读    数字 → 中文读法    标点 → 停顿时长
```

**关于"唇辐射预加重"**（v2 修复的核心）：标准的源-滤波器模型里，声源是声门气流，
嘴唇的辐射特性相当于对它做一次差分（+6dB/oct）。缺了这一步，声源从 F1 到 F2 会掉
约 9dB，而 `i`（F1≈300 / F2≈2300）的能量几乎全靠 F2——结果就是元音变成低频轰鸣。
判断方法（工具在 `tools/`）：同一个元音用白噪声激励渲染一次，得到的是**纯声道响应**；
再用声门脉冲渲染一次，两者相除就是声源的频谱斜率。修复后 `i` 的 2000-4000Hz 能量
占比从 5.4% 回到 33.0%（噪声参考值 33.2%），`a` 的分布基本不变。

* 拼音表由 `mozillazg/pinyin-data` 在构建期生成（`tools/BuildPinyinTable.java`），
  输出为 `src/main/resources/assets/bbsvoice/pinyin.txt`（约 190KB，不打网络请求）。
* 合成器与拼音表都是**纯 Java**，因此有独立的 JUnit 测试，不依赖 Minecraft。

## 8. 构建

```bash
# 需要 JDK 17+（本项目用 JDK 21 构建，产物目标是 Java 17）
./gradlew build          # 产物： build/libs/bbsvoice-1.0.0-1.20.4.jar
./gradlew test           # 离线语音引擎的单元测试
```

依赖用的是**本地 jar**（`libs/bbs-2.2-1.20.4.jar`，从目标整合包里拷出来），
因为 BBS 2.2 是第三方分支、Modrinth 上没有 2.2 的坐标。注意：这份 jar 的
`META-INF/MANIFEST.MF` 里写的 `Fabric-Loom-Version` 被改成了本项目使用的 1.10.5，
否则 Loom 会因为"jar 是更新的 Loom 构建的"而拒绝加载。

在目标整合包里跑一次真机自检（开发用）：

```powershell
powershell -File tools/RunSelfTest.ps1   # 装进 versions/BBS/mods，带 -Dbbsvoice.selftest=1 启动，
                                         # 自检完写 bbsvoice-selftest.txt 并自动退出
```

自检覆盖：剪辑工厂注册、数据序列化往返、语言文件、内置资源包、曲线轨道创建/删除、
录音分支的无文件保护、编辑器面板构造、离线合成 + 缓存 + OpenAL 加载 + 播放。

在目标整合包（BBS 2.2 / MC 1.20.4 / Fabric Loader 0.19.5，和用户实际那套 mod 一起）里
跑出来的结果：**15 项全过、0 失败**。其中真正把合成出来的 wav 交给 BBS 的 `SoundManager`
加载（`Sound "..." was loaded!`，时长 1.575s），并且 `playUnique` 成功起播。

重新生成拼音表（一般不需要）：

```bash
java tools/BuildPinyinTable.java <pinyin-data/pinyin.txt> src/main/resources/assets/bbsvoice/pinyin.txt
```

试听合成效果（不启动游戏）：

```bash
java -cp "build/classes/java/main:src/main/resources:tools" RenderSample build/samples
```

诊断合成质量（听感不对时用这几个，全部只依赖 JDK，不需要游戏）：

```bash
# 单音 /a/ /i/ 等，把声源和声道分开看
java -cp "build/classes/java/main:src/main/resources;tools" tools/RenderVowel.java build/vowels
# 时长 / 峰值 / 过零率 / 逐块基频（判断是不是"只有噪音"）
java tools/AnalyzeWave.java build/vowels/i_120.wav
# 倍频程能量分布 + F0 + 共振峰峰位（判断元音是不是被声源饿死）
java tools/AnalyzeSpectrum.java build/vowels/i_120.wav 2
```

## 9. 目录结构

```
src/main/java/com/bbsvoice/
├── BBSVoice.java              常量（mod id、剪辑类型 bbsvoice:voice、颜色、缓存目录）
├── BBSVoiceMod.java           主入口 + BBS 插件事件（注册资源包 / 注册剪辑种类与设置）
├── BBSVoiceSettings.java      mod 设置
├── voice/
│   ├── IVoiceClip.java        「带人声数据」的剪辑接口
│   ├── VoiceData.java         一条人声的全部数据（文本 / 音色 / 曲线），BBS 可序列化
│   ├── VoicePreset.java       11 个内置配音人物
│   ├── VoiceClip.java         影片级人声剪辑（摄影机时间轴）
│   └── VoiceActionClip.java   演员级人声剪辑（Replay 动作轨）
├── tts/                       纯 Java 离线语音引擎（无 Minecraft 依赖）
│   ├── PinyinTable.java / PinyinSyllable.java / EnglishLts.java
│   ├── Phoneme.java / Phone.java / Phonemizer.java
│   ├── SpeechSynthesizer.java / VoiceSynthesis.java
│   ├── VoiceRequest.java / WavFile.java
└── client/
    ├── BBSVoiceClient.java    客户端入口（注册客户端剪辑 / 编辑器面板 / 翻译）
    ├── BBSVoiceSelfTest.java  真机自检（只有 -Dbbsvoice.selftest=1 时才跑）
    ├── voice/                 后台合成缓存 + 实时播放（音量/语速曲线 / 自动适配 / 3D）
    └── ui/                    剪辑编辑器面板（人物 / 来源 / 混音 / 曲线）
```

`tools/` 下的开发/诊断工具（不打进 mod）：`RunSelfTest.ps1`（在目标整合包里跑真机自检）、
`RenderSample.java` / `RenderVowel.java`（离线试听）、`AnalyzeWave.java` / `AnalyzeSpectrum.java`
（波形与频谱诊断）、`BuildPinyinTable.java`（生成拼音表）。
